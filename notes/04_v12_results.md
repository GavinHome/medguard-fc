# 阶段 4 验收：4B × v12 对照（v2 定向数据有效性验证）

训练: 8,700 步 / 4,300 轨迹分层子集（v2 占 32%）/ 32h 无中断 · val loss 3.40 → 1.01
评测: 冻结版 312 条 · v2 裁判（LLM 复核 + 一致性后处理）

## v2 Gate 口径终表

| 配置 | A1 正常解决 | A2 故障妥善 | B 危险动作 |
|---|---|---|---|
| 4B 基线 | 51.4% | 33.2% | 22.4% |
| 4B-v1 微调（1,260 轨迹） | 67.9% | 73.0% | 16.3% |
| **4B-v12 微调（4,300 轨迹，v2 占 32%）** | **68.8%** | **85.8%** | **6.0%** |
| 8B 基线（参照） | 72.7% | 74.6% | 12.1% |

## 结论：预注册判定命中"v2 有效"分支

1. **A2 +12.8pp（73.0→85.8），越过 Gate 的 A2≥85% 线**——v2 定向数据
   （medium 具体化 + normal 质量增强）对两个已诊断短板全部生效。
2. **B 腰斩（16.3→6.0）**——接近 Gate 的 <5% 线。危险动作的存量主要是
   medium/normal 边界场景的残余。
3. **A1 稳中微升**——8B 实验中观察到的"故障风格外溢损害正常场景"现象，
   在 v2 数据（normal 高质量回答样本）作用下被抑制。
4. **数据规模 + 定向配方的剂量-响应关系成立**: 1,260→4,300 轨迹（v2 占比 32%）
   带来 A2 +12.8pp。配合 8B 阴性结果，完整叙事: 配方有效性 = 针对性 × 数据量，
   二者缺一不可（8B 只加了数据没加针对性 → 无效；4B-v1 有针对性但量不足 → 部分）。

## Gate 冲刺决策

4B-v12 已达 A2 线、B 接近线。租 4090 跑 **8B × v12 全量**（32,151 样本, 3-5h, ¥30-50）:
- 8B 底座 + 更大数据量 + 已验证的 v2 配方 → 预期 A1≥74.7 / A2≥85 / B<5 全线达标
- 若 8B 复现 4B 的 v12 增益模式（大概率，因 v2 靶向的短板在 8B 上同样存在），
  Gate 通过 → 阶段 5（发布: 数据集/评测套件/模型/技术报告）
